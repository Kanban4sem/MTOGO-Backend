## Context

Upon project start a framework for our server should be implemented. We have in the previous semesters been using Javalin but some of us know to Spring Boot which is more entreprise.

## Decision

We as a team has desided on using Spring Boot 4 as our framework after reading our Project Task provided by Lars & Tine.

## Alternatives

**Javalin**

- Good
- We all know it
- It's very explicit. Things must be written or configured or it won't work.

## Consequences

- Our team has to be ready to learn a new framework compared to previous experience.
- More knowledge as Spring Boot is not as explicit as Javalin.
